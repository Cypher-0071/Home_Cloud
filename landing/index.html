Personal Linux Control Plane

Your home server.
Accessible anywhere.

Turn a spare Linux PC into a reliable, self-hosted control plane. Manage files, stream live metrics, run Docker containers, and access an in-browser host terminal—behind CGNAT with zero port forwarding.

Capabilities

Built for single-node sovereignty

Designed with restraint. Fast, purposeful, and free of unnecessary abstractions.

⚡

Cloudflare Tunnel

Zero router configuration, port forwarding, or public IP exposure. Secure end-to-end HTTPS traversal through Cloudflare Edge.

>_

Browser Host Terminal

Full xterm.js powered PTY directly inside the dashboard. Seamlessly inspect containers or run bare-metal host commands.

📊

Real-Time Telemetry

Live Server-Sent Events stream CPU load, RAM allocation, disk partitions, and active network throughput without polling delay.

🐳

Docker Management

Inspect running containers, execute containerized shells, read logs, and manage Compose stacks with zero overhead.

📁

Jailed File Explorer

Fast and safe file navigation jailed to your user directory. Edit config files, upload assets, and browse storage safely.

🛡

Autonomous Systemd

Native background service supervision with auto-healing, restart resilience, and zero container runtime bloat for the control plane itself.
